JAVA FULL STACK CONTACT FORM APPLICATION

* Project Description
> A simple contact form application developed using Java, Spring Boot, HTML, CSS, and JavaScript.

* Features
> User-friendly contact form
> Name,Email, and Message fields
> Form submission using Spring Boot
> Submitted details displayed in the terminal
> Colourful success message after submission

* Technologies Used
> Java
> Spring Boot
> HTML
> CSS
> JavaScript
> Maven

* How to Run

1) Clone or download the repository.
2) Open the project in VS Code.
3) .\mvnw.cmd sprint-boot:run
4) Open http://localhost:8080/index.html in your browser
